Important correction to the app direction:

This app should NOT primarily be a crawler-first tool.

The primary workflow should be manual intelligence intake.

The user will browse the web manually and find useful provider information from screenshots, PDFs, Excel sheets, CSV files, webpages, provider forms, pricing sheets, clinic directories, and emails. The app should allow the user to upload or drop those files into the tool.

When a file is uploaded, the app should:

1. Preserve the raw uploaded file exactly as-is.
2. Create a folder-style evidence record, similar to how a laptop folder would organize files.
3. Allow the user to assign or confirm:
   - provider name
   - city
   - state
   - ZIP
   - service category
   - source type
   - notes
4. Extract useful structured data from the uploaded file.
5. Create or update a provider record.
6. Add the extracted provider/service/account/billing data to the smart search index.
7. Map the provider if address/location data is available.
8. Add uncertain items to a review queue.
9. Link every extracted field back to the raw uploaded source.

The app should become an Occu-Med Provider Intelligence Intake Hub.
